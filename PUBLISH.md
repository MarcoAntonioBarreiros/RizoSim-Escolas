# Publicação

## Publicação simples

O projeto é estático. Para publicar:

1. Envie o conteúdo deste repositório para um novo repositório chamado `RizoSim-Escolas`.
2. Ative GitHub Pages ou outro host estático apontando para a raiz.
3. Abra `index.html`.

## Offline

Todos os arquivos necessários estão no repositório. Não há CDN, imagens remotas, fontes remotas ou dependências de build.

## Recomendação para escola

- Testar no tablet Android que será usado na aula.
- Usar tela cheia quando estiver em projetor.
- Manter carregador conectado em aulas longas, pois canvas animado consome energia.
- Para turmas pequenas, usar a velocidade **Aula** apenas depois de os estudantes observarem o estado inicial.

## Não publicar sobre o repositório original

O repositório `MarcoAntonioBarreiros/RizoSim` foi tratado como somente leitura. Esta versão deve ser publicada como repositório independente.
